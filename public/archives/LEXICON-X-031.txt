FILE X-031 / 十只蠹虫
Ten Silverfish

归属：世界观
编目范围：十只蠹虫
相关人物：SILVERFISH_0 · 观察者坍缩
访问范围：NOTE

存档里出现的十只异常蠹虫，每一只可能对应一名外部观察者——锚点无法把完整的人送进来，于是用最廉价的活体对象保存「有人看过」这件事。

推演链（推断链）
这条是标准的模型式推断：先给观察，再给反例检验，最后给可推翻条件，而不是直接下结论。

1. 观察
   → 存档里出现十只蠹虫，位置与十次外部访问记录接近
2. 反例检验
   → 它们不遵循普通生成逻辑，且在不同录像中保持不合常理的个体差异——随机生成解释不掉
3. 模型
   → 锚点送不进完整的人，就用最廉价的活体对象保存「有人看过」这件事
4. 后果推演
   → 清除蠹虫可能切断观察者与存档的联系，也可能反过来伤到现实中的对应者；查明映射前不得攻击

未闭合：可推翻条件写得很明确：杀死其中一只后外部访问记录若毫无对应变化，或个体差异能被普通机制完整解释，这个模型就该废弃——两条都还没被验证过。

附注
1. 它们没有遵循普通生成逻辑，位置与十次外部访问记录接近。
2. 在不同录像里保持了不合理的个体差异，普通随机生成解释不了。
3. 结论带硬约束：查明映射规则前不得攻击，清除可能切断观察者与存档的联系。
4. SILVERFISH_0 的名字有两个来源，其中之一就是「在纸张和档案缝隙里存活的东西」。
