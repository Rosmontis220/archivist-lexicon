ARCHIVIST · LEXICON
FILE X-009 / W / A / O
World / Archive / Observer

归属：世界观
编目范围：术语表
相关人物：归档所 · 见证者坍缩
访问范围：CORE

世界、归档、观察者三个会互相改动的部分。三者在术语表里被并列写进同一个缩写，没有任何一方被放在「客观外部」。

推演链（定义出处）
这一组只有定义、没有可验算的实例，能补的是三者各自在别处留下的痕迹，按痕迹对齐后给出解释。

1. 术语表原行
   → W / A / O = World / Archive / Observer，「三个会互相改动的部分」
2. 取归档侧的职责：归档所
   → 保存可重新确认的状态与状态转移记录，并保留被推翻的旧版——它存的是「被确认过」，不是「发生过」
3. 取观察者侧的机制：见证者坍缩
   → 一种解释被公开后，其他可发现版本就失去被发现的路径——观察动作本身在改归档
4. 取世界侧的反例：选择噪声与预测盲点
   → 尚未被稳定记录的决定不进入高层读数，世界始终留着一块归档读不到的部分
5. 三者对齐
   → 世界产生未定选择 → 归档固定其中可确认的部分 → 观察者从归档反推世界，闭环成立

附注
1. 术语表只给了一行定义，没说明哪一方是基准；三者是循环关系，不是单向记录。
2. 观察者会改动归档这件事，在 v3 的系统错误里被写成一条独立报错：THE OBSERVER HAS ENTERED THE RECORD。
3. 归档只保存能重新确认的状态，所以它记录的从来不是世界本身，而是世界被确认过的那部分。
