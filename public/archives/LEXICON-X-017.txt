FILE X-017 / 归档所
ARC-00

归属：邮路终端
编目范围：邮件谜题
相关人物：归档中继 · 邮路终端
访问范围：CORE

归档所最早没有正式名称，雨前的记录里通常只写作「所」；它保存能够重新确认的状态与状态间的转移记录。

推演链（推断链）
归档所的名字是邮票文案给的，但「它靠什么活着」要靠西侧失效那段事故史才看得出来。

1. 起点：邮路终端第一枚邮票《归档所沿革残页》
   → 最早没有正式名称，雨前的记录里只写作「所」
2. 关键职责原句
   → 保存每次能够重新确认的状态与状态间转移记录，保留原件，也保留被推翻的旧版
3. 转折：西侧稳定锚第一次失效
   → 原本各自归档的记录开始互相出现，「雨」才作为事故类别进入主库
4. 结论
   → 归档所不是图书馆，是状态一致性机构；它保留旧版，正是为了在状态互相出现时还能对账

附注
1. 归档员的工作很少涉及解释，只登记发生过什么、保留原件。
2. 被推翻的旧版也一并保留，这套办法曾长期足够可靠。
3. 西侧稳定锚第一次失效后，「雨」作为事故类别进入主库。
