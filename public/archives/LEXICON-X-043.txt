GROUP（推箱）、TRADE（卡牌）、REVIEW（十六案卷复核）三部相互关联的网页小游戏，以钥匙链相连。

推演链（解谜链）
三部曲是三套完全不同的机制，但密钥共用一套编号规则（ARG-#系列）。

1. GROUP：推箱，把两个箱子推到两个槽位
   → 密码 28409163 → 密钥 ARG-#ARCHIVIST-60742
2. REVIEW：ACCESS KEY 输入 ARG-#REVIEW-73104，129 可解锁中文
   → 四关：推箱 / 九节管线 / 折叠投影 / 复核台 + 十六案卷
3. TRADE：红＞黄＞绿＞黑＞红，克制时数值 +2、同色相邻 +1
   → 赢下四局后拿枪击杀对手，进入真结局
4. REVIEW 三结局：红黄绿黑提交 / 右下最后一级阶梯按 E / 输入 MISTERY-12345 打 BOSS
   → ARG-#ARCHIVIST-57940 / MISTERY-12345 / ARG-#TRUTH-3927840
