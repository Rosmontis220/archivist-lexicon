Postal Terminal

相关人物：回返 · 归档所

以 GitHub 仓库 0-silverfish/postal-terminal 的 Issues 为投递口的邮件互动解谜；RETURN 是其核心机制。

推演链（解谜链）
五枚邮票各有独立的进门方式，串起来就是邮路终端的完整解法。

1. 一 · 雨前首封：点白色「30」圆圈让页面变深色
   → 下方出现新区域，LOCAL 输入 6825，领取邮票
2. 二 · 星幻_StarRev：从 html 隐藏 template 取出 QQ 号与解锁要求
   → 以 1142081338 作 ID 登录，自动领取
3. 三 · 未寄之门：GitHub 提示「四舍五入」→ 密码五位
   → 点位图橙色点在每行第几位 → 62415；先输 6241 再补 5，解锁潮汐主题
4. 四 · 未署名附件：按投递准则拍「白纸＋投递口」照片投递到 Issues #2
   → 收到序列号 C-4173-6，填入附件序列栏领取
5. 五 · 首席代理代表「#」：递交一个名为「联合处置决议.txt」的文本
   → 系统接受该名号，自动领取

附注
1. 五枚邮票为雨前首封、星幻_StarRev、未寄之门、未署名附件、首席代理代表「#」。
2. 投递准则要求先拍白纸与投递口的合影，再把照片投到虚拟投递口。
3. 投递不要求寄件人；被接受会收到一段 RETURN。
