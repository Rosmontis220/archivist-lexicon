FILE X-018 / ROUTE ZERO
ROUTE ZERO / ACTIVATION TRACE

归属：邮路终端
编目范围：邮件谜题
相关人物：邮路终端 · 未寄之门
访问范围：KEY

第三枚邮票《未寄之门》票面上的来源标记，写作 ACTIVATION TRACE / ROUTE ZERO；它不是一条能寄信的邮路，而是未激活的路留下的痕迹。

推演链（解谜链）
这条有输入、有解码、有结果：提示语 → 点位图 → 五位数 → 主题解锁。

1. 入口
   → 邮路终端第三枚邮票《未寄之门》，票面标 ACTIVATION TRACE / ROUTE ZERO
2. 提示
   → GitHub 侧提示「四舍五入」，指向五位数字
3. 解码
   → 点位图逐行数橙色点落在第几位 → 62415
4. 输入方式
   → 先输 6241，确认后再补 5；一次输满不被接受
5. 结果
   → 页面接受，解锁潮汐主题——ROUTE ZERO 就是「激活过但没走通」的那条路

附注
1. 标记本身是元数据，不是内容：票面上写信件从哪里来，而不是信里写了什么。
2. 同一枚邮票的密码 62415 由点位图逐行数橙色点得出，先给四位、再补第五位。
3. 解锁后页面切到潮汐主题，标记从装饰变成入口。
